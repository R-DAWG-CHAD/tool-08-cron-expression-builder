# ⏰ Cron Expression Generator & Schedule Translator

An interactive DevOps micro-tool designed to generate, translate, and simulate 5-field standard UNIX crontab schedules in real time.

## 🚀 Key Features

- **Interactive Field Inputs:** Separate visual input fields for Minute, Hour, Day of Month, Month, and Day of Week.
- **Plain English Translator:** Instantly translates complex cron expressions (e.g. `0 9 * * 1-5`) into human-readable sentences ("At 09:00 AM, Monday through Friday").
- **Next 5 Upcoming Execution Times:** Computes real-time future execution timestamps.
- **Crontab Snippet Builder:** Combines cron schedule expressions with shell script commands into copyable crontab syntax.
- **Frequency Presets:** Instant loading of common patterns (Hourly, Daily Midnight, Weekday Mornings, Weekly).
- **Dark Glassmorphism UI:** Modern, responsive dark mode interface optimized for terminal & web workflows.
- **Zero External Dependencies:** Native HTML5, CSS3, and JavaScript.
